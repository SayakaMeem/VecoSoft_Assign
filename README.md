🌐 Overview
A modern, responsive mobile Order Tracking experience built with React / Next.js and Tailwind CSS.
Designed for 360px - 430px viewport, with a centered phone frame on desktop for premium presentation.

Live: https://veco-soft-assign.vercel.app
Repo: https://github.com/SayakaMeem/VecoSoft_Assign
Design & Prompt History: https://www.meta.ai/share/c/sVIPTzdaqE

✨ Features
1️⃣ Visual Delivery Timeline
🔄 4 states: Processing → Shipped → Out for Delivery → Delivered
💫 Animated pulse for current step, ✅ checkmarks for completed, 📅 timestamps
🔗 Connected progress line with active state
2️⃣ Order Info
⏳ Estimated delivery date/time with live countdown
📦 Product summary (image, name, qty, price)
📍 Shipping address & Tracking ID: TRK382940192
📞 Sticky Contact Support button
3️⃣ Three Interactive Scenarios (Preview Toggle)
[!NOTE]
Built to handle real-world edge cases, not just happy path.

Scenario	Visual Treatment	Actions
⚠️ Delayed Order	🔴 Past estimated date, red/amber warning banner, strikethrough old date + new estimate	📞 Contact Carrier, 🔄 Reschedule, 💸 Refund
📦 Delivered but Not Received	🟠 Conflict state with orange warning	🚨 Report Issue, 👁️ View Proof of Delivery, 🔍 Request Investigation
🔍 Tracking Not Available Yet	⚪ Clean empty state (not broken), shimmer animation, skeleton timeline, info message	ℹ️ Info state
4️⃣ Polish & UX Craft
🦴 Loading skeleton (500ms on scenario switch)
🍞 Error toast state
🎨 Empty state illustration with pure CSS
📐 Clean hierarchy, 16-20px spacing, rounded-2xl cards, soft shadows
🔤 Inter font, minimal Apple / Shopify style
